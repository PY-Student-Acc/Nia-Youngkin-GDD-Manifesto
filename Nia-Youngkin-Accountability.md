I will stop information siloing in my team by having regular correspondence
outside of class.

We will set up a Discord group chat for us to communicate about the work on the project with one another.
We'll keep track of our individual tasks and goals via a HacknPlan project. 
Hacknplan's tools will help us keep to a schedule and accomplish our work by deadlines.
We'll have meetings where we assign tasks for the project so that everyone knows what the other members are working on.
We will make sure that the only tasks that are marked as active are ones being worked on so we can prevent merge conflicts 
by minimizing people working in the same area at the same time.
We'll help with the nerves of approaching deadlines by being there for each other. Anyone that is running into trouble with something they're working on 
should present this problem to the group for help.
This collaboration will help ease nerves. I know I feel the most stressed when i feel like I don't know what I'm doing, so being there to help one another can help resolve these issues.
